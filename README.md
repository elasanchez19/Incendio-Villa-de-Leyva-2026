# Incendio-Villa-de-Leyva-2026
Interactive mapping and analysis of the September 2026 wildfire in Villa de Leyva, Colombia, using satellite fire detections from NASA FIRMS (VIIRS, 375 m resolution).

The project visualizes the spatial and temporal progression of the wildfire around Cerro San Marcos and the Iguaque region, providing a geospatial perspective on the areas affected during the fire's most active days.

The interactive map was developed in R using sf and leaflet, with satellite-derived fire detections processed and visualized as geospatial data.
